Gambar yang dipakai aplikasi (nama file harus PERSIS seperti ini):

  logo_yayasan.png   -> logo Yayasan (persegi, latar transparan). Dipakai di
                        splash screen, halaman login, dan header Beranda.
  header_sekolah.jpg -> foto bersama Yayasan. Dipakai sebagai latar header
                        halaman Login dan Beranda.

Untuk mengganti gambar: timpa file di atas dengan gambar baru (nama file
sama), hentikan aplikasi, lalu jalankan ulang (flutter run). Gambar baru
tidak terbaca lewat hot reload.

Ikon aplikasi (Android & web) dibuat dari logo yang sama:
  android/app/src/main/res/mipmap-*/ic_launcher.png
  web/favicon.png dan web/icons/*.png
